# 项目作品集

## Destin 个人作品集网站

[打开双语作品集](https://archer1017.github.io/project-portfolio/)

首页为独立的 `index.html`，使用原生 HTML、CSS 和 JavaScript，包含可拖拽空间画廊、作品列表、详情图库、中英文切换及手机适配。照片与作品截图均内嵌，首页无框架或外部 JavaScript。

本站精选人生重开模拟器、安心财务、ClimbMate、AI 公益课堂、药品分辨器五项作品。`works/` 提供人生游戏的完整浏览器体验，以及财务、攀岩和药品管理的静态公开版本。攀岩云端图片分析不在公开版运行，药品扫描使用本地选择而非 OCR；AI 公益课堂仅展示实际页面，没有未部署的体验按钮。所有体验数据保存在当前浏览器，页面示例不代表个人财务、健康或训练记录。

兴趣区已加入攀岩、旅游、骑马与滑雪照片；滑冰和软笔书法继续预留。公开照片已清除 EXIF 等元数据，骑马和滑雪照片的可识别面部已遮挡。原始照片、私人分类记录、联系方式、学校与服务端凭证均不在公开文件中。

本地预览：在仓库目录运行 `python3 -m http.server 8000`。GitHub Pages 使用 `main` 分支根目录。首页使用用户指定的远程字体与影片；减少动态效果时跳过影片，影片不可用时仍可进入作品集。已验证五种视口、语言切换、菜单、键盘操作、手机竖滑及四个作品的主要本地流程。
