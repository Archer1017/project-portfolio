# 最后一班物业 / The Last Shift

Godot 4.5.1 第一人称夜班交接可玩原型的浏览器版。实际游戏使用原项目 GDScript 和场景，单线程 Compatibility / WebGL 2 导出，不是网页重制的模拟界面。

入口为 index.html；点击按钮后才下载并启动 game.html、game.js、game.wasm 与 game.pck。使用电脑键盘和鼠标，游戏内为中文，介绍支持中英切换。网页端首次加载约 52 MB。

当前可玩内容包括移动、交互、电话、物业电脑、五路实时监控、截图与观察报告、钥匙借还、日志及交接。完整恐怖剧情、异常事件、追逐、存档和结局尚未完成，页面明确标注原型阶段。刷新或离开会丢失本班进度。

游戏原始工程保持不变；浏览器导出使用独立副本。发布副本不包含原聊天、运行日志、个人联系方式、开发者电脑路径或缓存。截图来自游戏实际运行界面。Godot 与字体许可见 licenses/。
